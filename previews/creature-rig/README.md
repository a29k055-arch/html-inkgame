# 水墨生物分层动画测试

当前精修版：**rig-r3-shrimp-turtle-20261121**。虾加入平滑纸片转身，三根长须独立拆分并修复交叉处；乌龟补齐完整壳沿，四肢根部藏在壳下。保留已认可的鱼与龙效果。详情见 [R3 修正说明](MOTION_REPAIR_R3.md)。

**[直接在线打开](https://a29k055-arch.github.io/html-inkgame/previews/creature-rig/)**

这是独立的素材动画试验场，基于用户选定的 fish_04、dragon_04、shrimp_07、turtle_02。此测试不改变现有 V4 游戏机制。

电脑使用方向键或 WASD，手机拖动右下角摇杆。下拉菜单可切换四种生物、手动游动、自动巡游、静止微动、拉直中性姿态和原画对照。龙身可以从弯曲姿态展开为直线，再响应方向重新弯曲。

| 素材 | 分层数量 | 动作 |
| --- | --- | --- |
| fish_04 | 6 | 身体摆动、尾部推进、转向跟随 |
| dragon_04 | 14 | 多段扭动、延迟拖尾、身体拉直 |
| shrimp_07 | 11 | 小幅腹节、触须和足部摆动 |
| turtle_02 | 7 | 壳体稳定，头尾和四肢活动 |

38 层透明 PNG、38 张裁切贴图、骨架 JSON 和原图副本均保留在对应对象目录中。分层检查预览图有底色和标签，仅用于查看，实际游戏贴图为透明 PNG。

运行时是独立 JavaScript 木偶/网格实现：身体使用 WebGL 连续网格，附属层合成到 Canvas；无需专有 Live2D SDK 或构建工具。具体说明见 [分层结构](LAYERS.md) 与 [网页接入示例](runtime/README.md)。

当前保留原图可见笔墨，局部动作幅度受到控制；大角度肢体旋转仍需补画遮挡部分。手机布局及摇杆经过浏览器视口测试，真实手机性能需要继续实测。

本目录为 2026-11-20 发布的静态在线演示，运行时资源均使用相对路径，可从 GitHub Pages 子目录直接加载。
