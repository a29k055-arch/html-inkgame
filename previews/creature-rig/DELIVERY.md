# 四类水墨生物 · 可控动画素材包

上一轮修正版为 rig-r2-art-motion-20261120（2026-11-21 续完）：新增定向补图、隐藏关节延伸、鱼鳍根连续蒙皮、柔和转向、持续 S 形龙、虾左右镜像及乌龟间歇划腿。以 [本轮修正说明](MOTION_REPAIR_R2.md) 和最新验证记录为准，原图副本仍保留。

本包基于用户选定的 **fish_04、dragon_04、shrimp_07、turtle_02**。原图仍保存在 08_CONCEPT_CREATURES；本轮只增加素材和独立演示，没有接入或修改现有游戏机制。

## 打开演示

运行同目录的 StartDemo.ps1，打开它输出的本机地址（默认 http://127.0.0.1:8912/demo/）。电脑用方向键或 WASD，手机用右下角摇杆。可切换对象、速度、自动游动、静止轻动、原图对照和拉直姿态；骨架开关显示实际变形曲线。

演示依赖本机静态服务，正式网页部署时将本包按原目录结构放到自己的静态资源路径即可。离线文件直接双击 HTML 会受浏览器模块和资源读取规则限制，建议使用提供的启动入口。

## 运行方式

采用 **透明 PNG + JSON 骨架 + JavaScript 实时驱动**。鱼、龙以连续身体网格跟随方向；虾以低幅度腹部和须足动作；龟壳保持稳定，头、尾和四肢围绕连接点活动。身体层保持分开可编辑，运行时可合并连续网格以减少层间开裂。

这是一套独立可控的网页木偶/网格实现，不依赖商业 Live2D SDK，也不是 Cubism 模型文件。具体调用示例、资源生命周期与参数见 runtime/README.md。身体采用共享 WebGL 网格绘制以避免半透明三角片的接缝，再与附属层合成到 Canvas；WebGL 不可用时保留 Canvas 回退。浏览器标准接口参考：[MDN Canvas 2D](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D)。

## 龙身拉直

dragon_04 的原图曲线按身体中心线建立弧长映射，运行时可展开到直线，再变回游动和转向曲线。头、角须、四肢仍有独立素材，跟随对应身体位置。拉直检查是可控中性姿态，不是另一张重画龙图。

## 接入边界

四个对象都以同一接口对外提供方向输入、更新和绘制，可在独立网页游戏中调用。若后续接入当前 Unity WebGL 游戏，需要再将该渲染组件与角色状态/输入对接，或迁移相同骨架数据到 Unity 渲染；本轮没有改变当前 Unity 场景。

原画未画出的遮挡部位不会凭空出现。当前以保留原图、连续变形和克制局部活动为原则；正式使用前，应结合最终角色屏幕大小和允许的极端动作范围继续检查关节，并按需要补画隐藏结构。真实手机性能也需在目标设备实测；桌面浏览器的手机视口测试仅验证布局和输入。
