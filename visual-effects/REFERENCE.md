# 水墨视觉参考与参数

本目录的默认入口现在使用 **2d00e16 历史候选**，不是正式游戏的可变调参页。

- [冻结历史参考](./?mode=player&form=ink)：原始 app / fluid / material / config / fish / paper / body 与样式按提交逐字节保存。
- [修改前参考 ccddc4b](reference-ccddc4b/?mode=player&form=ink)：保留本轮开始前的视觉，方便回看。
- [对比实验室](lab.html)：历史候选 / 修改前 / 修复候选，支持小中大体型、直线、直角、原路返回、停止消散及可重复的时间定位。

## 历史依据和接受度边界

2d00e16 的交接记录明确记载：从 f8d3e2c 的主体、material / contain Shader 与涡量恢复上一版视觉，同时保留 reproject 等游戏兼容代码。本轮据此恢复正式游戏的 material 力场，保留主体种墨和浓淡光学；为世界轨迹分离添加局部柔边限制。

这是一份有提交记录支持的历史候选，**不能仅凭记录证明它就是用户最满意的小体型效果**。因此修改前源码也完整保留，并提供并排可选的对照入口；正式游戏采用恢复材质 + 修复历史轨迹的候选，不宣称与历史整幅 GPU 画面逐像素相同。

## 隔离规则

reference-2d00e16/ 与 reference-ccddc4b/ 不参与发布版本重写，每份 manifest.json 记录源码 SHA256。tests/visual-recovery.mjs 校验所有归档 JS 与样式。不能直接修改归档；未来需要新候选时新增目录。

正式游戏参数：src/ink/hero-visual-config.js。
实验室参数：visual-effects/lab-config.js，独立副本；修改正式游戏参数不会静默改写实验场景。
prototypes/ink/ 仍是共享底层工具的开发试验页，不再冒充冻结历史参考。

## 当前正式游戏轨迹参数

| 参数 | 当前值 | 含义 |
|---|---:|---|
| trailLifetime | 8 s | 模拟时间内的最长留存，暂停不会继续消散 |
| trailMaxWorldLength | 1250 | 实际走过的累计路程上限，含折返路程 |
| trailMinVisibleLength | 400 | 实际轨迹的前400距离不附加长度淡出；也控制采样精度，不外推、不延长生命期 |
| trailWidthScale | 0.58 | 参考半径18时的宽度基准 |
| trailTaper | 1.45 | 沿历史路程的收细指数 |
| trailFade | 1.4 | 年龄透明度衰减指数 |
| trailDiffusion | 0.7 | 随年龄增加的软边扩散 |

宽度 = min(29,18 × 0.58 × (出生半径/18)^0.38) × 路程收细。不同于按半径线性放大。最多256点；按距离等距重采样，急转提交拐点，逐段圆帽绘制，没有反向法线的长三角。纹理固定在世界坐标；重复经过的叠色受总层透明度0.48限制。停止后按每段出生时间自然衰减。

主体仅增加局部软限制：从小体型约2.15倍逻辑半径平滑收至大体型1.35倍；不改变碰撞半径、墨量或移动物理。尾迹使用真实路径，不由当前朝向生成。

## 验证方式

在实验室选择路线和体型，定位到同一秒数比较；原路返回不会把已记录点移到走过范围外。停止场景13秒时所有历史迹段消散。固定参考的源文件哈希独立于游戏发布键。

work/ 中保存本机截图与测试报告，不提交到发布仓库。网页和桌面浏览器模拟不能替代实体手机或用户对美术满意度的判断。
