# V4 start transitions

These ten atlases are conversions of the user's supplied local `Ink Matte (HD Set 1)/Transitions/Version 1` MOV files: (1), (3), (5), (8), (10), (13), (17), (21), (29), (35). See `manifest.json` for exact names, original SHA256 hashes, alpha coverage and byte sizes. This project does not assert that the source pack is public domain; distribution remains subject to the user's source-pack rights. No third-party download was added.

Originals inspected: opaque black-on-white H.264 MOV, 2048×1080, about2 seconds/59.94fps. White is converted to alpha0, black to opaque warm ink. New atlases:256×135 pixels per frame,36 frames,6×6 tiles, lossless WebP. Ten files total1,061,302bytes; decoded RGBA upper bound49,766,400bytes (~47.5MiB), cached once per page. Frame images are shared; no video decoder, independent fluid solver or per-run allocation of the atlas pool is needed.

Playback uses cover-fit (no aspect stretching), up to1.5DPR Canvas, 0.80s cover and0.72s reveal. The beginning fades in briefly because several original first frames already contain ink. Near the end of covering, a matching solid-ink seal ensures100% full-screen alpha before any asynchronous scene work, compensating for source borders/compression. On error an ordinary fade is the controlled fallback, not another opaque video.

API: `preloadStartTransitions()` resolves `{items,failed,total,decodedBytes}` and caches results. Failed image loads time out after8s and are excluded; if all fail, playback uses the fade fallback. `new StartTransition(canvas).run(async signal => {...prepare and draw scene...})` covers, awaits the callback, then reveals. Concurrent calls returnfalse. The callback must finish its first scene draw before resolving and may use the AbortSignal for async preparation. Scene timeout20s aborts/reveals/rethrows to the app for error UI; late asynchronous work must respect that signal. Visibility pauses animation time; resize redraws the current mask, including the guaranteed solid cover while preparation runs. Close native modal dialogs before starting, since modal top layers outrank ordinary canvas.

The old `assets/effects/transition.webp` and `MatteTransition` are untouched. Build-only conversion: `python tools/build-start-transitions.py "D:/ink_game/Ink Matte (HD Set 1)" --ffmpeg PATH`. Requires Pillow/FFmpeg only for rebuilding, no runtime dependency. Temporary contact sheet `work/start-transition-contact.png` is not published.
