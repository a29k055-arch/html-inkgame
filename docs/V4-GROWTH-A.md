# V4 方案 A：微墨 → 游墨（2026-11-15）

只实现前两个成长阶段；同一幅画、同一世界，无换地图或重置生态。基线1e8025c，恢复点checkpoint/v4-before-growth-a-1e8025c。V2/V3冻结标签不变。

## 参数与边界

- V4起始80墨，真实半径12。目标半径=min(170, sqrt(64+墨量))，保留平滑成长、实际mass=r²、原有吞噬比值。这里只改V4的墨量/面积换算；经典模式仍使用原来的4倍换算。死亡沿用30%体型保留，微墨下限半径12。
- 成长收益倍率：0.28+0.67/(1+墨量/850)，旧值0.18+0.44/(1+墨量/900)。前期更容易持续成长，但面积换算从4降为1，避免几口跨越尺寸层级。基础移动110、最低82、半径减速指数0.25，参考半径12；AI与加速仍共享速度规则。
- 实际墨量达到1000进入游墨，只触发一次。无时间门槛，临时龟体型不能触发，降墨/死亡不退回阶段一。
- 微墨相机PC2.3、触控2.2，随真实基础半径指数-0.10缓慢拉远。游墨基准1.12/1.08、指数-0.42；扩展插值1-exp(-dt*1.05)，3秒后恢复常规追踪1.8。屏幕半径上限110/72，缩放下限0.58/0.38，另受世界边界限制。墨龟不带动相机呼吸。
- 初始22 NPC=13小型r7–16、7中型r24–42、2大型r65–95。9只小型置于附近；中/大至少相距420/680。重排现有48个墨点到出生附近，不增加总数800或总质量。游墨仅新生成NPC改为30%小/45%中/25%大，已有NPC不缩放、不重建，仍可吃墨点和互吞。
- Drops：u=clamp((目标r-18)/80,0,1)，s=u²(3-2u)，名义半径=min(560,4.6r/AlphaExtent,r*(3.75+0.5s))，AlphaExtent≈1.06566。最终有效Alpha半径上限由4r放宽为4.6r；r≤18的旧效果不增大。r32/64/120的实际Alpha面积比旧版约+2.2%/+17.0%/+28.4%。扩散2.2→1.7秒，视觉和永久层共用Alpha与尺度，仍画在玩家下方。
- 本局用时取代倒计时，默认duration=null，不再强制840秒失败。65%总显画／90%墨区任一完成不变。临时显画、永久落墨和美术墨云仍独立。没有制作第三/第四阶段。
- 仅替换问题明显的第三变体：turtle-v4、lotus-leaf-v5、lotus-flower-v5；各类仍3种随机素材。素材来源见assets/pond/README.md。

## 实际验证

PC 1440×900原生WASD/Shift，触控390×844原生触点摇杆/加速；不改玩家资源、NPC、显画或完成状态。自动主动采食/追猎，rAF时钟×3仅缩短测试墙钟时间，以下均为游戏时间，不能作为性能测量。

| 最终1000墨配置 | PC | 触控模拟 |
|---|---:|---:|
| 第一次扩展 | 62.58秒 | 91.37秒 |
| 扩展后继续游玩 | 45秒 | 45秒 |
| 初始威胁、成长后可吞噬的同一存活单位数（最大） | 5 | 4 |
| 最终吞敌数 / 死亡 | 9 / 0 | 8 / 0 |
| 页面错误 | 0 | 0 |

首个1600墨候选实际98.34/116.10秒偏慢，因此收敛到1000。没有用固定时间强行晋级；自然路线有随机性，上述样本不保证所有玩家60–90秒达到。

受控GPU夹具另验证小r12/中r32.62、低速35/高速150、PC/竖横屏触控、三语言和暂停：3秒相机扩展可见面积约3.2倍；无fluid.clear/body.reset，保留12 FBO；世界、已有NPC、ink/r/mass、两层Mask及世界轨迹坐标不变。GPU墨雾重采样有轻微边缘变化（质心约6.5/10.7世界单位、Alpha面积比1.07/1.19），不能宣称逐像素完全不变。

NPC两层逐渐涂白、离开无回弹、短尾消散不损永久层通过。65%与90%胜利锁定、结算和Gallery刷新存档通过受控夹具；这不是自然整局通关证明。

针对性Node回归：growth-stages/growth-ecology/stage-drops、reveal-run、ink-reserve、collision-camera、pond-habitat/pond-persistence、nov10-mechanics、levels/save均通过。默认无时限后旧reveal-balance诊断明确设置840秒自己的诊断时长，不能据此宣称实际游戏有倒计时。

复现：启动tools/serve-preview.cjs；PLAYWRIGHT_MODULE指向安装的Playwright，然后运行tools/check-v4-growth-play.cjs [本地URL]（自然前两阶段）及tools/check-v4-growth-compat.cjs [本地URL]（受控兼容）。精简数据见V4-GROWTH-VERIFICATION.json。
