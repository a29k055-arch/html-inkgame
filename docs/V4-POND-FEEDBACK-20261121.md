# 《墨》V4 道具强化与体验改善交付

日期：2026-11-21。发布键：`v4-pond-feedback-r16`。本轮沿用原生水墨N，新增世界特效不进入流体或Reveal采样；屏幕速度线属于独立的界面反馈。

## 一、用户明确要求：磁铁

- 玩家周围出现一圈浅色引力光圈，三条波纹由外向内收束，到光圈为止，不穿过主体。
- 波纹有效范围读取实际机制的`arena.magnetField`，不是另算一个看起来更大的作用区。范围仍为`(coreRadius+85)×1.5/1.75/2`。
- 较小NPC受到引力：近级的逃跑速度被抵消一部分；体型差很大的可以逆着逃跑方向被拉回。相等/更大、无敌、水化或死亡NPC不吸引。
- 大小比较使用实际`coreRadius`，包括刺球内部实体核，不用装饰尖刺外径。
- 吸力按体型差、距离、道具档位连续变化。速度上限为玩家未加速基础速度的1.45倍；尺寸项`.08+1.32×(1-体型比)^.7`，外缘保留28%距离权重。参数集中在V4 items配置。
- 引力作为NPC本身运动后的额外世界位移，不改其觅食/逃跑意图、质量或竞争者身份；每最多6世界单位检查一次静态约束，防止穿荷叶实体或边界。
- 被吸NPC显示少量短墨线，PC最多6条、手机4条。不是所有NPC都画长连线。
- 引力范围不等于吞噬范围。仍需满足原来的体型与真实接触条件；结束或玩家死亡后停止吸力。

## 二、用户明确要求：鱼加速

- 三级鱼从+30/50/70%改为**+70/100/130%**，对应基础速度1.7/2.0/2.3倍。
- 全屏方向速度线随实际移动产生，中心与顶部HUD留白。PC最多22条、手机12条；旧线保留出生方向，转弯不会整体硬转；停止后淡出。
- 线条最大alpha系数.32、约1–1.7px，保留水墨审美，不叠新粒子系统或流体缓冲。
- 与晕染取较强速度效果，不叠乘。每次道具仍追加3秒，累计上限30秒。
- **晕染本身保持+30/50/70%**。原代码让鱼与晕染共用同一数组；已拆出`MANUAL_RUSH_TIERS`，避免误把手动晕染也提高到2.3倍。

## 三、用户委托设计：乌龟成长反馈

采用“真实长大＋一次扩张墨环”：拾取时发出两层柔和墨环，约1.05秒消散；前.45秒跟随实际成长半径，激活时只有三段很淡的润墨短弧。最多同时保留两次脉冲。

没有用贴片、硬壳或额外主体缩放假装变大。原本三级临时体型+30/40/50%、临时墨预算、半径上限、持续和到期恢复规则都保留；到达半径上限时不会靠视觉强行突破。

## 四、我自主增加的改善与配套修复

### 1. 吞噬声音分档＋变化

按吞噬前敌我真实核半径比分为小猎物(<.30)、中型(<.62)、大型三档，在音域、力度和包络上区分。水滴、古筝、琵琶三种已有风格均可使用。

同档不是固定一个音：五声音阶采用五步短句轮换，最近三次实际音高不完全相同，力度/包络另有三组小变化。连续吞噬不增加收益倍率，也不新增连击UI。保持四声部、全局40ms与墨点90ms节流。

### 2. 晕染状态诚实可读

原按钮显示“疾行·蓄墨中”“蓄墨未成”“松开落墨”，下缘细条显示时间与耗墨双门槛中较小的进度。达到条件时轻微亮边；按住期间按钮保持可交互，PC和手机松手都能释放。

仍需至少1秒且消耗12墨。没有改耗墨、冷却或释放范围；低墨量时不会仅因时间够了就误报“已蓄成”。三语手册同步解释双门槛。

### 3. 鱼拾取提示修正

原HUD没有鱼的buffSpec，通知会回退成Lv.1/+30%，与实际状态不符。现在读取真实rush档位，三级正确显示Lv.3/+130%；没有重新加入此前移除的鱼图标。

### 4. 强化速度的供墨安全修复

2.3倍速度检查发现，旧供墨在小体型前缘跟不上，实际流体覆盖不足。只在真实速度超过基础1.5倍时增加连续灌墨量：2.3倍时×1.64、最多×1.8；墨源宽度、逻辑碰撞和显示方式都不变。没有重新启用圆片或改掉普通速度的水墨风格。

## 五、验证

- 21个针对性Node测试脚本通过，覆盖引力大小/距离、dt、到期、经典隔离、荷叶约束、正常吞噬仅结算一次、鱼/晕染不叠乘、阶段、临时成长、声音序列、世界裁切与存档。
- 实际游戏PC和触控视口：磁铁三条波纹不进入内圈、小NPC有吸力/更大NPC无吸力；乌龟真实半径增长和临时墨到账；鱼2.3倍、停止淡出；低墨量未蓄成、真实鼠标/触摸长按蓄成后释放；中/日/英按钮文字均不溢出。
- 20组2.3倍速度流体检查：四体型×直行/转向/停止及手机视口，实体内.9r区域覆盖率最低约85.96%；44组普通运动基线通过，最低约81.33%。这是流体覆盖检查，不等于用户美术签收。
- PC/手机×横竖画×GPU/降级八组画框检查，包含新磁铁和乌龟世界特效，画框外泄漏0。全屏速度线按要求在界面层绘制，不参与显画。
- 四组横竖画×PC/触控回归：阶段过渡、完成动画、赏画滚轮/捏合、拖动、重置和Gallery保存/返回通过；这些是受控完成，不是自然游玩计时。
- 九组离线音频（三风格×三体型）非静音、无过载，峰值约.160–.271。真人听感与手机真机性能尚待反馈。
