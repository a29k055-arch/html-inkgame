# V4 animal icon source review — 2026-11-07

No new animal raster or SVG was added. The existing identifiable placeholder icons remain unchanged, as requested. Public-domain artwork is a candidate source, not automatically a readable 24–40px game icon. A consistent, production-ready turtle/koi/shrimp set with verified rights and verified small-size silhouette was not obtained in this pass.

## Primary sources checked

- [Attributed to Hokusai, Turtles — The Met](https://www.metmuseum.org/art/collection/search/57262): object page marks **Public Domain**, medium ink on paper, 18th–19th century. The page also states that open-access public-domain images are available for unrestricted commercial/noncommercial use. Promising turtle source; no crop/background removal/small-icon approval performed, so not shipped.
- [Shibata Zeshin, Tug-of-war of turtles — Smithsonian NMAA](https://asia-archive.si.edu/object/S2003.8.2180/): official page explicitly lists **CC0** and ink/color on paper. A multi-animal narrative print rather than a finished isolated item icon. Candidate only.
- [Fish and water weeds — Smithsonian](https://www.si.edu/object/fish-and-water-weeds%3Afsg_F1911.226): search index states public-domain media and describes fish, shrimp, and carp. Direct page retrieval failed with HTTP404 in web tool. No downloadable source/rights proof was packaged, so not used.
- [Sea-turtle-watercolor — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Sea-turtle-watercolor.jpg): author Frits Ahlefeldt's own work, file-specific **CC0** declaration confirmed. It is a watercolor sea turtle rather than a matching monochrome ink icon set. Not adopted.
- [Qi Baishi, Shrimps 1954.781 — Cleveland Museum of Art](https://www.clevelandart.org/art/1954.781): official object page explicitly says **This artwork is known to be under copyright**. Rejected for unlicensed use despite search results describing ink painting.
- [Qi Baishi, Shrimps — UMMA](https://umma.umich.edu/objects/shrimps-1949-1-200/): object result directs publication users to an image rights request form, no clear unrestricted asset license established. Not used.

## User-supplied material that would help

One clearly licensed monochrome ink turtle, one swimming koi, and one shrimp, ideally with transparent background or clean paper, large enough to extract a clear silhouette. Game targets are about 40px on the map and 23px in the Buff HUD. Keep animals visually distinct after reduction, with moderate gray wash and strong structural strokes. A license/artist permission allowing game use and modification is needed. Do not substitute emoji or repeatedly redraw low-quality icons just to replace the placeholders.
