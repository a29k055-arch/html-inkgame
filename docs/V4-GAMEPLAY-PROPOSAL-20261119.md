# 《墨》V4：玩法诊断与下一轮提案

日期：2026-11-19。本文是设计提案，不是已实施功能清单。黑洞、弹幕、晕染扩展与数值调整均未加入本轮代码。

## 1. 判断与证据边界

推荐先实施A“吞噬反馈与节奏”，然后仅原型B中的一种攻击。当前最重要的缺口是：玩家做对事情之后，奖励表达与下一步目标不够明确。增加弹幕可以丰富遭遇，但不能代替成长回报。

依据为当前源码、真实浏览器运行和受控渲染/机制检查。没有新玩家访谈或完整自然局统计，故下述“无聊原因”是有代码依据的设计假设，不能视为已证实的留存结论。旧tools/pace-probe.mjs使用8Hz近似圆刷图，不代表当前30Hz真实alpha显画，不能证明5–7分钟达标。

有限参考：[poncle官方介绍](https://poncle.games/vampire-survivors)强调简洁操作与生存成长；[《孢子》官方商店介绍](https://store.steampowered.com/app/17390/SPORE/)强调各成长阶段具有不同目标与挑战。本文借鉴的是短操作链与体型关系反转，不引入它们的完整升级系统。A/B取舍和所有参数均为针对《墨》的设计推断，不是这些来源的结论。

## 3. 五个主要痛点与改进假设

1. **成长缺乏可感知的拐点。** 墨点微增，阶段切换又拉远镜头。先呈现0.2–0.35秒短暂聚墨/身体舒展，再进行现有退镜；配一个不同于拾取的低频水声。不要夸大真实碰撞大小，也不强震屏。
2. **玩家不知道下一只值得追谁。** 墨量阈值主要藏在文字title内，手机难发现。仅提示最近一只“现在可吞”或“还差少量墨可吞”的目标，配很淡的局部标记，不加任务列表和满屏箭头。危险圈仍只用于实际危险。
3. **遭遇选择重复。** 多数眼球/刺球最终都变成同一体型比较。A先通过觅食、短追逐、撤退的权重区分；B再检验方向性攻击是否增加走位决策。
4. **主动操作的期待与回报错位。** 晕染既耗墨又缩小，但不伤敌、不击退、不消弹；新手可能误以为它是攻击。先让“加速中”和“已蓄成可落墨”可辨认，再讨论是否扩展。
5. **后半程容易从捕猎退化为补空白。** 重叠Drop与涂白会削弱净进度。优先用已有重叠返墨、原画有墨进度引导，以及局部猎物供应，避免统一提高倍率或取消NPC涂白。

改进循环建议：发现一只值得追的猎物 → 判断追逐/躲避/借荷叶恢复局势 → 吞噬或选择晕染显画 → 立即收到与风险相称的反馈 → 看见原来不能吃的目标变得可吃 → 反捕并显露新画面。

## 4. 晕染：先修正理解，再增加一种用途

实际规则：按住加速并耗墨；每秒耗墨为ink×.10×clamp(r/140,.3,1.8)×(.28+.72×min(held/3,1))；最长5秒。至少1秒且累计消耗12墨才释放落墨，半径clamp(sqrt(spent)×13,70,560)；冷却min(3,1+.6×(held-1))。短按或未达墨量门槛不会落墨。

受控检查：起始17墨，单独运行真实tickBoost共5秒，消耗约1.889墨，不触发bloom；100墨也仅约11.113墨。不是键失效，而是双门槛在早期难满足。本轮未改此规则。

下一轮优先：用既有按钮与主体周围淡墨弧区分“正在加速”和“落墨已蓄成”；不要让玩家误以为按够时间必然落墨。门槛是否改为体型相对门槛，须单独批准和对照测试，不能顺带改掉成本体系。

若加入弹幕，首选仅增加**释放前缘消除实际接触到的敌弹**。不附加全屏清弹、持续无敌、吸附、伤害和击退。消费墨量会暂时失去体型优势；释放可开一条路，但不能替代接近并吞噬敌人。荷叶用于重整与观察，离开庇护后才有追猎风险。先不允许躲在荷叶中无风险反复清场。

## 5. 两套可行方案

### A：增强已有吞噬循环（主方案）

- 按敌我体型比区分小猎物、同级目标、大型威胁三档反馈：水滴、聚墨、一次低频脉冲；大敌使用现有大Drop并强调显画过程，不先改收益。
- 1–2秒连续吞噬窗口只推动音阶与轻量墨纹，不加连击倍率或额外HUD。密集拾取继续遵守声部上限。
- 阶段升级按“体型变化→镜头舒展→新猎物目标”表达；不会更改真实碰撞和吞噬阈值。
- 下一可吞目标提示与局部猎物空窗检测。若连续约10–15秒没有合适目标，在原NPC预算内调整2–3个低位重生位置，不能突然在玩家面前送食。
- 道具用实际效果开/关的一次声画变化说明收益，优先处理乌龟体型、鱼加速、虾吸墨；不新增道具。
- 收尾让未显画的主要画面区域更容易被找到；优先观察已有90%有墨目标和重叠返墨的效果，再考虑显画效率。

### B：低密度弹幕与生态分工（后续原型）

不增加NPC总量，黑洞占现有名额。先只让少数单位拥有攻击资格。

敌种分工有两种可行实现：

| 分工 | 黑洞 | 眼球/刺球 | 代价 |
|---|---|---|---|
| 硬分工 | 主动吞噬、成长、竞争者 | 吃墨点成长、发弹；取消对NPC主动/接触吞噬 | 最清楚，但改变所有NPC自由吞噬的旧规则，生态更像移动炮台 |
| 软分工（推荐） | 承担大多数主动捕猎，竞争者优先采用该外观 | 保留公共吞噬与自由成长，主动行为重觅食/站位，降低追杀NPC权重 | 复用系统，保留连续生态；需要防止“刚发弹又贴身吃掉”读不清 |

两类都不以出生层限制成长；死亡仍按出生层低位重生。眼/刺保留吞噬玩家的公共体型规则及现有红圈，不把弹幕命中当作直接吞噬。软分工只是建议，尚未被用户采纳。

初始攻击参数（均待实测，不是已发布平衡）：

| 参数 | 刺球 | 眼球 |
|---|---|---|
| 初始攻击 | 有明显逃生缺口的环形8发 | 固定方向3发、约35°扇形 |
| 周期 | 4–5秒 | 3.5–4.5秒 |
| 前摇 | .7秒收缩/尖刺朝向提示 | .6–.8秒注视，发射前锁定方向 |
| 后期上限 | 10–12发，先不双轮 | 5发、约50°，不持续追踪 |
| 弹速试值 | 100–150世界单位/秒，结合遭遇距离调整 | 同左，优先确保从预警结束到命中仍约.7秒可反应 |

共同约束：同屏最多2名攻击者、错峰；手机活跃弹预算24、PC40，寿命约2秒，越画框销毁；预警覆盖轮廓要适配镜头。安全缺口至少容纳玩家真实直径及操作余量，体型过大时扩大缺口或取消该次射击，不能出现数学上无解的弹环。

第一版弹只作用玩家、不友伤、不显画、不涂白，视觉与可拾墨点明显区分；命中轻度损墨，初始可试当前墨量0.8%、最少1/最多40，所有弹共享约1秒保护，遵守既有死亡/复活规则，不逐弹叠伤或秒杀。数值只是验证起点。荷叶阻挡命中，不能让视觉上的庇护失效。

黑洞美术只需旋转浓墨与内旋灰阶，初版不做全场吸力/引力物理。不要为了第三外观复制AI、成长或碰撞系统。现有竞争者只能有一只。

### 比较

| 维度 | A | B |
|---|---|---|
| 爽感/成长动力 | 直接强化每次成功与下一目标 | 遭遇变化更大，但需要A提供回报 |
| 对抗性 | 提升有限，仍重体型与路线 | 更强，有预判、清路与接近窗口 |
| 开发量/复杂度 | 小到中；事件、提示、镜头时序 | 中到大；攻击调度、弹池、碰撞、读招和移动端QA |
| 性能 | 新增开销较低，限制声部/粒子即可 | 需固定预算、对象池、屏外休眠；不为每发弹启动流体 |
| 手机 | 保持现有移动＋长按 | 同样按键，但手指遮挡与大体型逃生空间更难处理 |
| 水墨美术 | 风险低 | 高密度弹/预警会遮画，必须克制 |
| 商业独立游戏适配 | 先验证“吞噬成画”本身是否有吸引力 | 可增强预告片与重复游玩差异，但不能证明市场接受度 |

建议：A完整做一轮，再只测眼球扇形＋晕染消弹。若玩家已愿意打完、但遭遇仍单调，再加入刺球和黑洞软分工。不要一次上三种敌人后才发现核心奖励仍弱。

## 6. 四阶段节奏与平衡

目标时间预算，而非倒计时或实测结果：

| 阶段 | 目标累计时间 | 不加新技能也能产生的变化 |
|---|---|---|
| 微墨 | 0–60秒 | 看见巨物、学习躲避和荷叶；尽快完成第一次主动捕猎 |
| 聚墨 | 60–150秒 | 稳定追捕同级目标，吃下刚才的威胁，晕染回报可理解 |
| 游墨 | 150–270秒 | 大Drop连续显画、反捕旧巨敌、路线覆盖而非只扫墨点 |
| 成画 | 270–360/420秒 | 画面信息完整、完成主要空白，保留少量威胁与最后一次大吞噬 |

不先统一提高成长倍率。分别测：小猎物空窗、NPC收益/墨点收益比例、晕染花费、涂白净损失、Drop重复面积、末段找空白用时。道具加强发现与兑现反馈，不靠延长所有增益来掩盖节奏。

画作必须持续作为奖励：前期每次吞噬露出可辨笔触，中期大Drop露出山石/人物等有辨识度区域，末期是作品趋于完整；同一位置反复露白则缺乏新信息。可先利用已有freshArea/重叠返墨做提示与观察，不马上增加强制画作任务。

商业定位建议为“每局5–7分钟，靠追逐、成长与取舍完成一幅可收藏水墨画”。在这一承诺被真实玩家验证前，不扩充大量内容或设计付费成长压力。画作收藏是完成奖励，不能独自承担中途每十几秒的动力。

## 7. 下一轮可逐项批准与验收的任务

| 优先级 | 小任务 | 验收方法 |
|---|---|---|
| 1 | 记录真实局阶段时间、吞敌间隔、晕染蓄成/未蓄成、显画净增与末段用时 | 3–5位新玩家各1局；所有人都记录完成/失败/退出，不能只算通关者；这是形成性测试，不推算市场留存 |
| 2 | 三档吞噬声画反馈，连吞音阶 | 不看数字能区分小猎物与大敌；不增加明显遮画和强震动 |
| 3 | 身体→退镜的阶段时序、一个下一猎物提示 | 升级后玩家能说出“现在可以追谁”，没有假体型/隔空碰撞 |
| 4 | 晕染蓄成提示；单独评估12墨门槛 | 新玩家能解释加速成本与何时落墨；比较现规则与经批准的相对门槛版本 |
| 5 | 按真实局数据调整局部猎物/收尾，不改总倍率 | 完成者中位5–7分钟，持续>20秒无目标的空窗减少；退出者不被统计隐藏 |
| 6 | 若A仍缺对抗，单眼球扇形＋晕染消弹原型 | 小中大可躲、手机可操作、荷叶可信，弹幕不遮盖画作与墨点 |

最小高收益组合：大小吞噬音色分档、阶段升级独立提示、晕染可蓄成状态、下一只猎物可读性。先用现有奖励确认这些改动有效，再调数值。

暂缓：复杂引力、NPC弹幕友伤和反射连锁、满屏弹海、每次吞噬停顿、持续强震屏、更多主动键、装备/卡牌/技能树。它们成本高，不能直接解决当前已找到的奖励表达与目标空窗。

操作已经足够：移动决定路线与接近，长按晕染决定墨量成本/机动/显画，荷叶决定撤退时机；加入一个可读的攻击方向后就有追、绕、等、退、释放的选择。无需先增加按键。
