# 墨 · 视觉效果 / 水墨表現

独立的水墨视觉试作。基于用户认可的第四轮流体风格，第五轮加强墨芯、尺寸关联与柔和互动；不替代旧版可玩游戏。

## 三项试作

- **墨体形态 / 墨のかたち**：鼠标或WASD移动，Shift疾墨，按钮泼墨。浓墨中心标示受控位置，边缘和尾迹由真实流动密度形成。主体大小滑杆同时控制墨芯、补墨、尾迹和扩散边界；变小时清除旧尺寸的流体残留。
- **互动水墨 / 墨にふれる**：悬停推动现有墨流，拖动或触摸注入新墨。推动力度约为原来的四分之一，影响范围缩小，自动流动和涡量更柔和。
- **宣纸显影 / 紙に描く**：拖动流动墨体还原已有原画；原画辅助按钮不计完成度。未开始操作以及重置后不自动作画。小屏切换时显式恢复画布尺寸。

主要界面、说明、按钮与无障碍名称同时显示中文和日文。高/均衡/省电调整模拟网格；触屏默认均衡。Escape暂停/继续。旧版入口保留，旧游戏中文文案为此前本地修改。

## 技术与边界

原生JavaScript、WebGL2浮点双缓冲、平流、压力投影、涡量约束、有界MacCormack密度校正。material.js以统一半径驱动墨芯、输运、补墨和尾迹范围；没有绘制一个固定的Canvas圆形作为主体。此前body.js轮廓方案仅作历史对照，不参与当前渲染。

这是二维水中墨的视觉方案，仍未包含真正的三维薄膜/自由表面/表面张力求解。需WebGL2及EXT_color_buffer_float，不支持时显示中日说明。视频仅作参考，未复制或上传。没有新增账号、服务器、多人玩法或历史作品存档。
